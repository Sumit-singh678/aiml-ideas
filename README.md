## 🚀 The six-step build loop

```text
  01  DEFINE       What question should the project answer?
  02  FIND DATA    Use an openly licensed or synthetic dataset.
  03  BASELINE     Start simple before trying a complex model.
  04  TEST         Keep test data separate; choose a fitting metric.
  05  INSPECT      Look at mistakes, bias, and uncertainty.
  06  DOCUMENT     Explain setup, results, limits, and next steps.
```

### A good first portfolio project includes

- A clear problem statement and dataset source/license
- Reproducible setup instructions
- A simple baseline and an appropriate evaluation metric
- A few visualizations and examples of incorrect predictions
- Honest limitations—especially for health, education, safety, and security
